Đối soát VNPay

Giao dịch VNPay hệ thống ghi nhận trong ngày (cọc đơn, cọc đoàn, thẻ quà tặng, hoàn cọc). Tải sao kê từ cổng merchant VNPay lên để so khớp từng mã giao dịch.

So khớp với sao kê VNPay

Tải thẳng file .xlsx / .csv xuất từ cổng merchant VNPay: hệ thống tự tìm cột Mã giao dịch VNPay và Số tiền theo tiêu đề (bỏ qua dòng trạng thái thất bại / hủy). File tự làm thì để cột 1 = mã giao dịch, cột 2 = số tiền. Hoàn tiền ghi số âm vẫn được.
